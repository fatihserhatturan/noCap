How it works

  1. 1 Drop an audio file

    MP3, WAV, FLAC — any format works.

  2. 2 AI does the heavy lifting

    Demucs isolates vocals. Whisper transcribes every word with millisecond-accurate timestamps.

  3. 3 Syllables meet the grid

    Each syllable is aligned to the beat grid using the CMU Pronouncing Dictionary for stress patterns.

  4. 4 Explore the flow map

    Hover, click to play, highlight rhyme chains, and inspect timing metrics bar by bar.

Features

🥁

Beat Detection

BPM and full beat grid extracted directly from the waveform via librosa.

🎤

Vocal Separation

Demucs htdemucs model isolates the vocal stem for cleaner transcription.

✍️

Whisper Transcription

OpenAI Whisper medium model with cross-attention DTW for ~10 ms word accuracy.

📊

Flow Metrics

Density, syncopation, pocket (ahead / center / behind), and timing variance per bar.

🎨

Rhyme Detection

Phonetic matching for perfect, slant, assonance, and internal rhymes — color-coded on the grid.

📦

Track Library

Save analyzed tracks and re-open them instantly — no re-analysis needed.

Developer Quick Start

git clone https://github.com/fatihserhatturan/nocap.git
cd nocap

python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,separator]" && pip install openai-whisper

cd frontend && npm install
npm run desktop:dev

The first analysis downloads the Whisper model (~1.5 GB) into ~/.cache/whisper/ — one time only.
